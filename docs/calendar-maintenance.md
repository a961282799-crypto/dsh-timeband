# 日历维护

当前正式数据只有 2026 年。新年份必须以国务院办公厅公告或政府网站转载为依据，不能从工作日日历推导峰谷计费日；周末包括调休上班日，仍按谷时段。

## 用户更新

在插件弹窗展开「规则、日历与提醒」，点击「获取新日历」，从本项目下载 JSON 文件并导入。成功后立即应用并保存在当前应用来源的本地存储，重启后继续生效；选择「恢复内置」可清除导入数据。

导入会替换整份日历，以文件中的 `years` 为覆盖范围。需要同时保留多个年份时，下载同时包含这些年份的汇总文件。没有对应年份时，插件保持未知年份提示。

## 文件格式

参考 [2026 年完整示例](../calendars/2026.json)。文件为 UTF-8 JSON，最大 64 KB，包含：

| 字段 | 要求 |
|---|---|
| `schemaVersion` | 固定为 `1` |
| `years` | 已核对的完整年份，升序、不重复，每年必须有假期条目 |
| `verifiedOn` | 人工核对日期，格式 `YYYY-MM-DD` |
| `source` | HTTPS 政府网站公告地址，域名为 `gov.cn` 或其子域 |
| `holidays` | 放假日期闭区间 `[起始日, 结束日]`，按起始日排序、不重叠，每段限同一年 |

跨年放假应拆成分别属于两个年份的区间。列入 `years` 就表示已核对该年的全部放假安排，不仅是部分节日。地址校验不能证明内容正确，维护者需人工核对原公告。

## 发布新日历

1. 查阅当年政府公告，整理完整放假区间，保留已有年份及其日期。
2. 在 `calendars/` 新增以年份命名的汇总文件，更新核对日期与本次公告来源；在此文档保留历年来源链接。
3. 若同时更新默认内置数据，让 `src/calendar.ts` 导入新的汇总文件。不要在另一个位置维护重复日期表。
4. 运行 `npm run check`，特别核对第一天、最后一天、调休周末及跨年倒计时。
5. 推送文件供现有用户导入；默认数据更新时同时发布插件新版本。

## 公告来源

- 2026：[政府网站转载](https://www.lufengshi.gov.cn/swlfsjj/gkmlpt/content/1/1199/mpost_1199727.html)，2026-09-30 核对。
